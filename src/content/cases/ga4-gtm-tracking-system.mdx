## Overview

이 케이스는 광고 클릭 이후 사용자가 실제 문의까지 이어지는지 확인하기 위해 전환 측정 구조를 정리한 사례입니다.

좋은 광고 성과 분석은 광고 매체 화면에서 끝나지 않습니다. 캠페인, 소재, 키워드, 랜딩, 문의 이벤트가 연결되어야 실제 성과 판단이 가능합니다.

## Problem

광고 클릭 수와 전환 수는 보이지만, 다음 질문에 답하기 어려운 상태였습니다.

- 어떤 캠페인이 문의하기 클릭을 만들었는가?
- 어떤 소재가 제출완료까지 이어졌는가?
- 문의하기 버튼 클릭과 실제 제출완료가 구분되는가?
- 네이버 파워컨텐츠, 블로그, 랜딩페이지 유입을 같은 기준으로 비교할 수 있는가?
- 사용자는 CTA를 누르기 전 어떤 행동을 했는가?

이 상태에서는 성과가 좋다/나쁘다를 말해도 근거가 약해집니다.

## My Role

- UTM 네이밍 규칙 정리
- GTM 이벤트 기준 설계
- GA4 전환 이벤트 확인 구조 정리
- 문의하기 클릭과 제출완료 이벤트 구분
- Clarity로 CTA 전후 사용자 행동 확인
- 캠페인·소재·키워드별 전환 판단 구조 제안

## UTM Naming Logic

UTM은 단순히 붙이는 것이 아니라, 나중에 분석할 수 있는 규칙으로 관리해야 합니다.

```txt
utm_source   = 유입 채널
utm_medium   = 매체/방식
utm_campaign = 캠페인 목적 또는 상품군
utm_term     = 키워드 또는 타겟
utm_content  = 소재/랜딩/버전
utm_id       = 내부 관리 ID
```

예시 구조:

```txt
source / medium / campaign / term / content / id
naver / search / pc_keyword / 한의원마케팅 / c076_main / amd_c076
meta / paid_social / lead_test / lookalike / video_a / am_001
```

## Event Structure

| 이벤트 | 의미 | 판단 기준 |
|---|---|---|
| page_view | 랜딩 진입 | 유입량과 랜딩별 비교 |
| cta_click | 문의하기 클릭 | 사용자가 관심을 보였는가? |
| form_start | 폼 입력 시작 | 전환 의도가 있는가? |
| form_submit | 제출 완료 | 실제 리드로 볼 수 있는가? |
| lead | 최종 전환 | 캠페인 성과 기준 이벤트 |

핵심은 **문의하기 클릭과 제출완료를 같은 전환으로 보지 않는 것**입니다.

## Analysis

측정 구조를 정리하면 다음과 같은 분석이 가능해집니다.

- 캠페인별 CTA 클릭률 비교
- 소재별 제출완료 전환율 비교
- 키워드별 리드 전환율 비교
- 랜딩별 이탈 구간 확인
- Clarity 녹화 기반 사용자 행동 확인

> 성과가 좋다/나쁘다를 감으로 말하지 않기 위해, 캠페인–소재–키워드–전환 이벤트가 연결되는 추적 구조를 먼저 정리했습니다.

## Decision

측정 구조가 정리되면 광고 운영의 판단 기준이 바뀝니다.

| 기존 판단 | 개선 판단 |
|---|---|
| 클릭 수가 많으니 좋은 캠페인 | 제출완료까지 이어지는지 확인 |
| CTR이 높으니 좋은 소재 | CTA 클릭 후 이탈률 확인 |
| 전환 수가 있으니 유지 | 진성문의/미팅 데이터와 연결 필요 |
| 매체별 보고서만 확인 | GA4 기준으로 채널 통합 비교 |

## Action

- UTM 규칙 문서화
- GTM 태그/트리거/변수 기준 정리
- GA4 이벤트명과 전환 이벤트 기준 분리
- Clarity로 CTA 전후 행동 확인
- 광고 보고서에 캠페인/소재/키워드별 전환 기준 추가

## Result / Expected Impact

이 구조를 통해 광고 성과를 매체별 숫자로만 보는 것이 아니라, 사용자가 광고 클릭 이후 어떤 행동을 했는지 확인할 수 있게 됩니다.

특히 다음 액션을 더 명확하게 잡을 수 있습니다.

- 소재 문제인지
- 랜딩 문제인지
- 타겟 문제인지
- 폼/CTA 문제인지
- 리드 품질 문제인지

## Limitation

웹 이벤트와 실제 영업/상담 결과가 완전히 연결되지 않으면 최종 CAC와 매출 기여도를 정밀하게 계산하기 어렵습니다.
