## Overview

이 케이스는 외국인 대상 병원 예약 앱의 유입–설치–전환 퍼널을 설계한 사례입니다.

웹 퍼포먼스와 달리 앱 마케팅에서는 클릭 이후 설치, 설치 이후 인앱 행동, 그리고 실제 문의/예약 가능성을 함께 봐야 합니다.

## Service Context

서비스는 외국인 사용자가 한국 병원을 탐색하고 예약할 수 있도록 돕는 앱입니다.

주요 타깃은 다음과 같이 나뉩니다.

- 중국어권 사용자
- 일본 사용자
- 대만/홍콩 사용자
- 동남아 사용자
- 미국/영어권 사용자

국가별로 검색 의도, 의료 관광 니즈, 광고 채널, 메시지 반응이 다르기 때문에 하나의 캠페인 구조로 보기 어렵습니다.

## Problem

앱 마케팅에서 설치 수만 보면 실제 비즈니스 성과를 판단하기 어렵습니다.

중요한 질문은 다음과 같습니다.

- 어떤 국가에서 유입된 사용자가 설치 후 행동하는가?
- 설치 이후 회원가입, 병원 검색, 문의, 예약으로 이어지는가?
- Meta/TikTok/Google 중 어떤 채널이 실제 인앱 행동으로 이어지는가?
- 광고 클릭 후 앱 설치와 딥링크 이동이 제대로 연결되는가?
- 병원 입점/문의와 B2C 사용자의 행동을 어떻게 분리해 볼 것인가?

## My Role

- 국가별 유입 채널과 메시지 구조 정리
- 앱 설치 이후 인앱 이벤트 기준 설계
- Airbridge 기반 어트리뷰션 흐름 점검
- Meta/TikTok/Google Ads 연결 이슈 확인
- B2C 사용자 퍼널과 B2B 병원 파트너 퍼널 분리

## Funnel Design

```txt
Ad Impression
  → Click
  → Store Visit
  → Install
  → App Open
  → Signup
  → Hospital Search
  → Inquiry
  → Reservation
```

## Data & Metrics

| 단계 | 주요 지표 | 판단 질문 |
|---|---|---|
| 광고 | CTR, CPC, CPM | 국가별 메시지가 반응하는가? |
| 설치 | CPI, Install Rate | 클릭이 설치로 이어지는가? |
| 활성화 | App Open, Signup | 설치 후 실제 사용이 있는가? |
| 탐색 | Search, Detail View | 병원 탐색 의도가 있는가? |
| 전환 | Inquiry, Reservation | 병원 문의/예약 가능성이 있는가? |

## Analysis

앱 마케팅에서 설치 수는 시작 지표일 뿐입니다.

설치 수가 많아도 앱 오픈, 병원 검색, 문의 이벤트가 낮으면 성과가 좋은 채널이라고 보기 어렵습니다. 반대로 설치 수가 적더라도 특정 국가/키워드/소재에서 문의 가능성이 높은 행동이 나타나면 확장 후보로 볼 수 있습니다.

> 앱 마케팅에서는 설치 수보다 설치 이후 어떤 행동이 병원 문의와 예약 가능성으로 이어지는지가 더 중요하다고 판단했습니다.

## Decision

| 상황 | 판단 | 액션 |
|---|---|---|
| 설치 수 높음 + 앱 오픈 낮음 | 저품질 유입 가능성 | 크리에이티브 메시지 재검토 |
| 설치 수 낮음 + 문의 이벤트 높음 | 고의도 세그먼트 가능성 | 국가/키워드 확장 실험 |
| 특정 국가에서 검색 이벤트 높음 | 의료 니즈 명확 | 해당 국가 랜딩/광고 강화 |
| 딥링크 연결 불안정 | 측정 누락 가능성 | Airbridge 링크/이벤트 재점검 |

## Action

- 국가별 캠페인 구조 분리
- 설치 이후 핵심 인앱 이벤트 정의
- Airbridge, Meta, TikTok, Google Ads 연결 상태 점검
- 앱 설치 광고와 검색 기반 리다이렉트 흐름 비교
- B2B 병원 파트너 문의와 B2C 사용자 전환 이벤트 분리

## Result / Expected Impact

이 구조를 통해 국가별로 단순 설치 수가 아니라, 실제 병원 문의/예약 가능성이 높은 사용자를 구분할 수 있습니다.

또한 앱 마케팅 성과를 다음 단계로 확장할 수 있습니다.

```txt
Country → Campaign → Install → In-app Event → Inquiry → Reservation
```

## Limitation

초기 앱에서는 인앱 이벤트 수가 충분하지 않을 수 있습니다. 따라서 초반에는 정량 지표뿐 아니라 검색어, 지역, 문의 의도, 병원 카테고리 등 정성 정보도 함께 봐야 합니다.
