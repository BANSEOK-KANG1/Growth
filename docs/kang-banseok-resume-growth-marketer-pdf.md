## Experience

### 글로벌알파미디어 — 퍼포먼스마케터 · 2025.12 – 2026

해외 타깃 **리드형 캠페인**을 Meta·Google·Naver·TikTok에서 운영하며, GA4/GTM 기반 전환 측정과 리드 품질 판단을 연결했습니다.

- Meta·Google·Naver·TikTok **멀티채널 운영** — 채널별 CPA·리드 품질 비교 후 **예산 재배분**
- **GA4/GTM**으로 문의 클릭→폼 진입→제출 완료 이벤트 분리 — 매체별 **퍼널 전환율**을 동일 기준으로 비교
- CPA 단독이 아닌 **리드 품질·미팅 전환율** 기준 예산 유지·축소·확장 후보 도출 (월 **₩3,800만+** 규모)
- 소재·랜딩·타깃 조합 **A/B식 운영** — CPA·CVR 변화를 숫자로 개선안 작성
- 날짜·매체·캠페인 기준 **Raw 통합 구조** 설계 — Sheets/Looker Studio 리포트 자동화
- 반복 측정·보고 업무 **문서화·표준화** — UTM·이벤트·리포트 기준을 팀 협업용으로 고정
- 데이터 기반 **운영 우선순위·테스트 포인트** 정리 → 주간 리뷰 후속 액션으로 연결

**앱 그로스 — 외국인 대상 병원 예약 앱**  
앱 설치→예약 전환 흐름을 채널·국가별로 분리해 분석할 필요가 있었습니다. **Airbridge** 이벤트 구조를 검토하고, 유입 채널별 전환 차이를 비교할 수 있는 분석 흐름을 설계했습니다.
